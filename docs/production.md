# 给想复现这支宣传片的人

本仓库由 Jed杰德哥公开，收录《个人订单驾驶舱》宣传片最终工程及交付。产品本体请看 [trade-order-dashboard-demo](https://github.com/jedliuai/trade-order-dashboard-demo)。

## 制作路线

先读取项目需求和真实演示截图，整理 60 秒故事板与 30 fps 时间轴，用 GPT-6.1 Sol 协作编写 React / Remotion 场景代码。用户反馈推动了截图边框、第一帧点题、客户矩阵、货款平衡、Demo 两行入口、Excel 痛点、数据链点亮与停留时间的调整。

配乐采用用户选定的渐进电子律动，通过 NumPy / SciPy 合成。鼠标点击与翻纸来自公开录音，按关键帧定位；数据链八个短音与八次点亮一一对应。转场最后采用奶油底衔接的淡出淡入，去掉反复扫光。

最终纯音乐与音效版完成后，画面冻结。另写紧贴 13 个场景的讲解稿，用本机 CosyVoice2-0.5B 生成两种女声样段，用户选择“女主播”。按 15 段生成、适度调整少数片段速度、为两处点击留白，再用 FFmpeg 直接复制原版视频流并合成新音轨。两版画面相同。

封面先确认文案，再确认三张 4:3 风格样图中的第二版。最终文案为“广告公司要失业了？”“AI 一次直出宣传片”“个人订单驾驶舱”“项目作者：Jed杰德哥”。其余四种比例分别生成和排版；极小尺寸误差以不缩放原像素的画布补边校正。9:16 署名另行上移，留出更宽底部边距。

## “一次直出”的含义

这是作者确认的封面传播标题。实际工程经过多轮需求反馈和验收，并非单次调用直接生成全部成品。成片来自代码渲染，声音包含程序合成、第三方录音和本地 TTS，封面使用独立的 AI 图像生成流程。

## 可以复现到哪一层

1. **直接看最终作品**：仓库与 Release 保存原始最终 MP4 / WAV / PNG，SHA-256 可核对。
2. **改画面重新渲染**：安装 Node 依赖后编辑 Remotion 源码。帧数、时间轴和素材完整，但浏览器、字体和编码环境的差别可能造成新的文件或像素差异。
3. **用已生成语音重做混音**：15 段 WAV 和任务表均已附带，不需要先运行模型。
4. **重新生成声音**：配乐可用仓库内程序生成；TTS / ASR 要自行准备对应模型与环境。预设和权重不在公开包内。
5. **再做封面**：提示词和最终文件已附带；同一提示词的随机生成结果可能不同，不保证逐像素复现。

## 产品表述的边界

合同信息一次登记后业务可以持续关联；后续发货、收款等进展仍需据实更新。片中的 Excel 提效是流程展示，不是对任意报表、模板、数据量作一秒完成承诺。演示的六类导出为当前功能；这里没有增加定时自动发送或无限自定义模板的能力。“当前贡献较低”是客户价值矩阵的位置提示，不给客户贴永久标签。

画面中产品标题保留既有“外贸订单驾驶舱”场景表达；社交封面和项目入口统一使用作者确认的项目名“个人订单驾驶舱”。
