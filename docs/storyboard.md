# 60 秒递进律动版

最终版保留完整价值主线、客户矩阵、货款平衡和两行 Demo 入口。观众一眼认出 Excel，逐个听见数据关联，完整看见经营总览，配乐随故事向前推进。片内“外贸订单驾驶舱”是产品的业务场景表达，项目与封面名称为“个人订单驾驶舱”。

| 时间 | 画面与节奏 |
| --- | --- |
| 0–3 秒 | 第一帧点题：外贸订单驾驶舱 |
| 3–7 秒 | 三张表加入绿色 Excel 标识，反复填表与复制 |
| 7–13 秒 | 客户→合同→产品→数量→金额→发货→收款→利润，每半秒点亮一颗，八个短尾敲击音递升 |
| 13–19 秒 | 经营总览：前 2.5 秒完整展示，1 秒连续推近，后 2.5 秒指标展示 |
| 19–22 秒 | 今日优先事项，20.6 秒鼠标咔哒 |
| 22–29 秒 | 合同、生产执行、发货和到账 |
| 29–34.5 秒 | 客户矩阵：右上绿色高价值，左下橙色当前贡献较低 |
| 34.5–39 秒 | 客户、产品、月份/财年、趋势；微观细节到宏观全局 |
| 39–43 秒 | 客户与产品集中度 |
| 43–47.5 秒 | 货款平衡，橙绿提示卡与箭头 |
| 47.5–51 秒 | Excel 导出与真实下载反馈，48.767 秒鼠标咔哒 |
| 51–55.5 秒 | 数小时手工制表→一次点击，六类报表 |
| 55.5–60 秒 | 品牌出现时仍处于音乐高潮，随后自然收束 |

数据链节点在第 225 至 330 帧，每 15 帧点亮一个。已点亮节点保留绿边、绿底、绿图标与清楚的黑色文字，当前节点短暂外扩脉冲，连接线随节拍向右推进。完成语提前在最后几个节点点亮时出现，让整句话有阅读时间。

取消整屏扫光、中心夹开和纸页透视翻动。场景用 0.8 秒的淡出/淡入，经原有奶油底衔接；两套标题不同时出现。总览内部使用同一张真实截图连续改变裁切范围，避免两张截图叠影，白色留边和强调线始终跟随同一个容器。

配乐采用用户选定的渐进电子律动，120 BPM：先和弦与疏朗拨弦，再逐层引入鼓和贝斯，中段成型，后段增加高音主题、十六分打击和鼓 fill，导出收益与品牌落点保持高潮。纸声更轻，八颗递升音只用于数据链，两处真实鼠标点击保留。
